# PyLab
Useful Python examples, e.g. plots, numerical/data analysis.
Initially created in 2023.
Please make sure you don't have the PyLab of matplotlib installed, which I believe is now deappreciated.
cosmo_tools.py and PyLab.py contains some useful functions, to use them from any locations, add this to your bash_profile:
export PYTHONPATH=Current_Path:${PYTHONPATH}

Enjoy!
